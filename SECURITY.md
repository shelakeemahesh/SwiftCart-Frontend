# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The SwiftCart team takes all security vulnerabilities seriously.

If you believe you have found a security issue, please **do not open a public GitHub issue**. Instead, report it privately to the maintainers:

- **Email**: `shelakeemahesh@gmail.com`
- **GitHub**: Private vulnerability reporting via [Security Advisories](https://github.com/shelakeemahesh/SwiftCart-Frontend/security/advisories)

### Response SLA
- Initial acknowledgement: **Within 24 hours**
- Assessment and reproduction: **Within 48 hours**
- Fix deployment or advisory release: **Within 7 business days**
